## 🚀 5. EAS Build & Release Step-by-Step Instructions

Follow these exact terminal commands to generate the production Android App Bundle (`.aab`) and upload it to Google Play Console:

### Step 1: Login & Configure EAS
```bash
cd d:\Pandit-booking\pandit-app
npx eas-cli login
npx eas-cli build:configure
```

### Step 2: Generate Production Android App Bundle (.aab)
```bash
npx eas-cli build --platform android --profile production
```

### Step 3: Download & Upload to Google Play Console
1. Download the generated `.aab` binary file from the Expo dashboard link.
2. Go to **Google Play Console** -> Select **Panditoo Partner**.
3. Navigate to **Testing** -> **Internal testing** (or Production).
4. Click **Create new release**, drag and drop the `.aab` file.
5. Paste the Release Notes from below and submit for review.
